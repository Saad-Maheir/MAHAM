# مهام | MAHAM (عامل المهام)
### منصة التكنولوجيا المالية العراقية الرائدة لإنجاز المهام اليومية والاشتراكات الاستثمارية المعتمدة (PWA)

---

## 📌 نبذة عامة عن المشروع والبيئة الهندسية
تم بناء وتصميم منصة **"مهام | MAHAM"** وفقاً لأعلى معايير الأمان المصرفي والسرعة الفائقة لتعمل كـ Progressive Web App (PWA) متوافقة 100% مع بيئات الاستضافة السحابية والمشتركة لشركة **Hostinger (PHP 8.2+ & MySQL via PDO)** وجاهزة للربط الفوري مع **GitHub CI/CD Pipelines**.

تم تنفيذ **المرحلة الأولى (Phase 1: Core User Application & Database Foundation)** بدقة متناهية، وبنية تحتية مهيأة لاستقبال **المرحلة الثانية (Phase 2: Admin Command Center)** مباشرة على نفس الجداول وقواعد البيانات دون أي إعادة هيكلة.

## 🛡️ المعايير الأمنية المطبقة (Ironclad FinTech Security)
1. **Atomic Database Transactions & Row Locking (`FOR UPDATE`):**
   - حماية كاملة لعمليات خصم الرصيد، سحب الأرباح، شراء باقات VIP، وإضافة مكافآت المهام ضد هجمات التكرار وتضارب العمليات (Race Condition & Double-Spending Attacks).
2. **Server-Side Anti-Cheat & 24h Cooldown Engine:**
   - التحقق الزمني من إنجاز المهام يتم على خادم الـ PHP بناءً على الطوابع الزمنية المشفرة (Cryptographic Verification Nonces)، مع منع تام للاعتماد على ساعات المتصفح العميل.
   - فاصل زمني صارم 24 ساعة للباقة المجانية (5 مهام كحد أقصى) وإلغاء فوري للتبريد عند الترقية إلى باقات VIP المفتوحة (`∞`).
3. **MIME-Type & Binary File Security:**
   - فحص رؤوس الملفات الثنائية عبر `finfo_file` لصور إشعارات التحويل المالي، ومنع تنفيذ ملفات السكربتات الخبيثة نهائياً عبر ملف `.htaccess` داخل مجلد المرفقات.
4. **Prepared Statements with Disabled Emulation:**
   - إغلاق ثغرات حقن الاستعلامات (SQL Injection) نهائياً عبر محرك `PDO` بضبط `ATTR_EMULATE_PREPARES => false`.
5. **CSRF & XSS Mitigation:**
   - توليد رموز حماية من تزوير الطلبات عبر المواقع (Anti-CSRF Tokens) وفحص تطابقها مع كل عملية معدلة للبيانات.

## 🚀 دليل النشر والتشغيل على Hostinger (Deployment Guide)

### الخطوة 1: استيراد قاعدة البيانات (MySQL Database)
1. ادخل إلى لوحة تحكم Hostinger (**hPanel**).
2. انتقل إلى **Databases** -> أنشئ قاعدة بيانات جديدة باسم ومستخدم وكلمة مرور قوية.
3. افتح **phpMyAdmin**، واختر قاعدة البيانات المنشأة.
4. اذهب لتبويب **Import** وارفع ملف `database/schema.sql` لتوليد كافة الجداول، الفهارس، والباقات الافتراضية.

### الخطوة 2: ضبط ملف البيئة والأمان (`.env`)
1. في المجلد الرئيسي لبيئة الاستضافة، أنشئ ملف `.env` انطلاقاً من `.env.example`.
2. عدل بيانات الاتصال بقاعدة البيانات:
   ```env
   DB_HOST=localhost
   DB_PORT=3306
   DB_NAME=اسم_قاعدة_البيانات
   DB_USER=اسم_المستخدم
   DB_PASS=كلمة_المرور_السرية
   ```
3. عدل أرقام المحافظ المعتمدة للإيداع (زين كاش، آسيا حوالة، كي كارد) بما يطابق حسابات الشركة الرسمية.

### الخطوة 3: أذونات المجلدات (File Permissions)
تأكد من أن مجلد المرفقات يمتلك صلاحية كتابة للمستخدم:
- `uploads/receipts/` -> `0755` أو `0775`

### الخطوة 4: التحقق من تشغيل التطبيق
افتح رابط النطاق في المتصفح؛ ستعمل المنصة مباشرة مع الشاشة الترحيبية السينمائية (Cinematic Splash Screen)، ونظام التبويبات العائم للموبايل، والتصميم الكامل الداعم للغة العربية والعملة العراقية (د.ع).
